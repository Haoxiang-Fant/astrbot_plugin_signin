点击「加载」读取功能开关...

每个系统可独立开关：关闭后对应指令在群聊中提示「功能已被管理员关闭」。默认全部开启，保存后立即生效（重启后保留）。

点击「加载」读取运行参数...

修改后点击「保存并立即生效」即可（无需重启插件）。参数保存在 plugin_data 的 data.json 中，重启后仍保留。

点击「加载」读取已注册的活动模块...

勾选启用活动，并可修改每个活动的起止时间 / 简介 / 参与要求 / 自定义参数，保存后立即生效（重启后保留）。活动的编写方式见 ACTIVITY.md。

导出会把 **用户存档（data.json）+ 自定义配置（后台.txt / 宠物商店.txt / 作物.txt / 肥料.txt / 贷款套餐.txt）** 打包为单个 JSON 文件下载；导入会用所选文件覆盖以上全部文件（建议先导出备份）。
