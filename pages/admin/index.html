导出会把 **用户存档（data.json）+ 记录数据（records.json：宠物属性变化/自动购买/自动打工/商店价格记录）+ 数值配置（game_items.json：商店/打工/玩耍/作物/肥料/贷款套餐）** 打包为单个 JSON 文件下载；导入会用所选文件覆盖以上全部文件（兼容旧版 txt 备份，建议先导出备份）。

⚠️ 危险操作区（默认道具数据）

点击后需输入弹窗中显示的 6 位验证码确认。农场系统（种子/作物、肥料）与宠物系统（商店商品）的道具数值将替换为插件包 Benchmark data/game_items.json 中的默认数据，立即生效。当前自定义数值会被覆盖（打工/玩耍/贷款套餐不受影响），建议先导出备份。

👥 群昵称同步

点击按钮后，插件通过机器人 API（aiocqhttp / OneBot）拉取所有群聊的成员昵称，存为排行榜用户默认昵称（data.json → group_names）。同步后：排行榜优先显示「用户触发功能时记录的最新昵称」，其次显示本同步数据，最后才是存档昵称 / 掩码。成员较多的群可能需要一点时间，请勿频繁点击。

🌐 局域网开放

开启后，与本机同一局域网内的设备访问 http://服务器IP:端口 并登录 AstrBot 后，需输入本密码才能进入该后台；本地访问（127.0.0.1）免密。每次局域网访问都会记录设备/IP/密码是否正确，可加入黑名单禁止。管理员私聊机器人发送「管理网址」获取局域网访问地址。

点击「加载」读取同义口令...

同义口令 = 词义相近的口令别名，发送别名与发送对应指令效果完全相同（降低记忆指令的难度）。例如默认预置 打卡 → 签到、我的宠物 → 宠物、存金币 → 存款、治疗 → 治疗宠物、财富榜 → 金币排行 等。目标指令从下拉列表选择，同义词不能与标准指令同名；保存后立即生效（重启后保留）。

点击「刷新」读取全部宠物的运行记录...

展示全部宠物的当前状态（属性/档位/虚弱）、正在进行的活动与剩余时间，以及自动购买 / 自动打工信息（打工基准金币、最近购买·使用×N 记录、自动打工记录）。可按状态（活跃中/已停用）与状态档位（T1~T4）筛选，并按档位/等级排序。点卡片上的「自动购买」「自动打工」开关（开/关）可直接切换该用户的开关——开启自动购买会自动开启自动打工，未开自动购买不允许开自动打工。虚弱宠物显示红色「停用」标签（自动购买/自动打工暂停执行，需先「治疗宠物」）。点击宠物卡片进入宠物详情页——分门别类展示该宠物的各项详细信息（基本档案 / 当前状态 / 特殊记录 / 自动化 / 仓库道具），以及按操作时间排序的属性变化记录（每日结算 / 打工 / 玩耍 / 使用道具 / 治疗 / 自动购买 / 自动打工，每条默认折叠、点击展开属性条可视化）。
