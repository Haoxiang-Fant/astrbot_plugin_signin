# =========================================================
# 作物配置：管理员可在 WebUI（农场后台页）编辑
# 每个作物以 [作物:名字] 开头，后面跟「键=值」行
# 字段：
#   种子价格      —— 购买该作物种子的价格
#   种子卖出价格  —— 卖出该种子的价格
#   产量          —— 每块地基础产量
#   成熟作物价格  —— 每个成熟作物的卖出价格
#   收获经验值    —— 收割时获得的农场经验
#   最低农场等级要求 —— 种植该作物所需的农场最低等级
#   成熟时间      —— 成熟所需分钟数
# =========================================================
