# astrbot_plugin_signin

一个功能丰富的 AstrBot 群聊娱乐插件，集成了 **签到、左轮手枪、宠物养成、金币银行、农场、金币红包、活动中心** 等系统。

> 🤖 本插件由 [DeepSeek](https://www.deepseek.com/) 大模型辅助开发完成。
>
> 💡 所有指令**直接发送即可触发，无需前缀或 @ 机器人**；金币、好感度、宠物、战绩等数据**跨群聊共享**（按用户维度）。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 签到 | 金币、好感度、宠物经验、属性丸 |
| 左轮手枪 | 金币下注轮流开枪 |
| 宠物系统 | 养成、每日结算、打工、玩耍、商店（分类卡片展示） |
| 金币银行 | 存款生息、下一个 4:00 解锁、利息自动入账 |
| 金币账单 | `查询流水` / `流水查询` / `消费记录`，图片展示金币变动流水 |
| 金币红包 | `金币红包 <个数> <总金额>` 发红包，`开` / `开红包` 抢红包 |
| 农场 | 解锁土地、种植收割、施肥、售卖、作物/肥料自定义 |
| 活动中心 | `活动` 查看进行中的活动；活动模块可扩展（见 ACTIVITY.md） |

## 一、签到

- 发送 `签到` 触发；每天每人限签一次（跨群共享）
- 随机获得 **30~300** 金币、**0.01~1.0** 好感度
- 好感度初始等级为 **0**，每满 **10** 点升 1 级，最高 **10** 级
- 拥有宠物后，签到额外获得 **10~60** 宠物经验；额外奖励池（互斥）：**40% 不送任何东西 / 30% 获得 1~5 个「属性丸」/ 30% 获得 1~5 个「农场经验球」**
- **属性丸**：使用后**随机 2 个属性**获得 **+5~20** 提升，**每日最多 3 次**（可在 WebUI 配置）
- **农场经验球**：使用后获得**升级所需总经验的 5%~20%** 农场经验，**每日最多 3 次**（可在 WebUI 配置）
- **特殊机制**：属性丸对应宠物、农场经验球对应农场；若未开通对应功能，签到获得/使用时**自动转为金币**（每个 10 金币）
- 签到时显示宠物每日结算结果与提醒
- `签到` / `我的签到` 响应为**图片**
- `签到帮助`：查看签到模块指令（图片）
- `游戏帮助`：查看全部模块指令（图片，总入口）

## 二、左轮手枪

| 指令 | 作用 |
| --- | --- |
| `装弹 <子弹数> <金币>` | 开局（子弹 1~6） |
| `加入` | 加入本局 |
| `开始` | 发起人提前开始（≥2 人） |
| `开枪` | 轮到你的回合时开枪 |
| `我的战绩` | 胜率 / 净收益 / 谁拿你最多金币 / 你拿谁最多金币 |

- 响应内容均为**图片**（含开局/加入/开枪/战绩等）
- 7 个弹匣随机放 n 发子弹，轮流开枪，中弹者判负
- 失败者扣全部赌注：**双人局手续费 10%**（赢家得 90%），**三人局手续费 5%**（两赢家平分 95%）
- 开局会明确提示**30 秒超时**；超时后若无人加入，主动提醒「超时结束，无事发生」，游戏结束无任何损失

## 三、宠物系统

### 指令

| 指令 | 作用 |
| --- | --- |
| `解锁宠物` | 花 1000 金币领养（每人限一只） |
| `宠物` | 查看属性 / 等级 / 经验 / 当前活动（图片：宠物信息卡 + 属性条 + 空闲进度条） |
| `更改宠物名字 <名字>` | 给宠物起名 |
| `打工` / `打工 <名称>` | 打工列表 / 打工 |
| `玩耍` / `玩耍 <名称>` | 玩耍列表 / 玩耍 |
| `商店` | 查看商品（分类卡片图片） |
| `购买 <道具名> [数量]` | 购买道具（不填数量 = 1 个，最多 999） |
| `使用 <道具名> [数量]` | 使用道具（不填数量 = 1 个，最多 999） |
| `背包` | 查看道具 |
| `宠物帮助` | 玩法总览 |

- `宠物` 指令回复为**图片**（1.7.1）：顶部宠物信息卡（名称/状态/等级/经验/升级进度条）→ **宠物属性条区** → **底部空闲进度条**（详见下文「宠物指令图片」）

### 属性与结算

- 宠物属性：饱食度、口渴值、体力、心情值、健康度、经验
- 解锁初始属性：饱食度 100 / 口渴值 100 / 体力 100 / 健康度 120 / 心情值 80 / 经验 0
- **升级经验（1.7.1）**：所需经验 = **当前等级 × 100**（Lv.1→2 需 100、Lv.2→3 需 200、Lv.3→4 需 300…），最高 **100** 级；**旧数据按宠物经验总值自动匹配新等级体系**
- 健康度上限 **200**；饱食/口渴/体力/心情的上限随健康度变化
- **每日零点结算**（懒结算：玩家当日首次操作时自动补结算）：
  - 按健康度档位扣除饱食/口渴，恢复体力，增减心情
  - 按饱食/口渴/心情的「三档」增减健康度
- 结算体力提升 >100 → 提示「休息得很好」；健康度 ≤39 → 提示「生病了」；任意属性第三档 → 提醒照料

### 打工 / 玩耍 / 商店

管理员编辑插件目录下的 **`后台.txt`** 即可自定义（保存后立即生效，无需重启）：

- **打工**：要求（最低等级/健康度/心情值）、消耗（体力/饱食/口渴/健康/心情/时间）、报酬（金币/经验）
- **玩耍**：要求、消耗（体力/饱食/口渴/健康/时间）、报酬（经验/心情值），并有 1% 概率触发「捡到钱了」+100 金币（每个周期最多 2 次）
- **商店**：道具名、类型（食品/饮料/药物/玩具）、价格、各属性效果（可为负数表示负面效果）
- 打工/玩耍完成后宠物按该项的 `需要时间` 进入**冷却**，**打工与玩耍共用一个计时器**：冷却期内不能进行新的打工或玩耍（1.7.1）
- **消耗字段名兼容**：健康消耗支持 `消耗健康度` / `消耗健康值` / `消耗健康` 任意写法（如 `消耗健康值=5`），其余消耗字段为 `消耗体力` / `消耗饱食度` / `消耗口渴值` / `消耗心情值`

### 打工 / 玩耍列表图片（1.7.1 布局）

发送 `打工` / `玩耍` 时以图片展示，**图片高度随内容自动适应**：

- **图片结构**：`<用户名称>` 标题 → **宠物信息卡片**（横跨整行，宽度 = 下方内容卡片一行布局总宽度）→ 分割线 → **打工/玩耍内容卡片**（每行 `WORK_CARD_COLS` / `PLAY_CARD_COLS` 个，默认 2，可在运行参数页调整 1~4；卡片宽度默认 **522 = 原 290 的 180%**，可在运行参数页 `WORK_PLAY_CARD_WIDTH` 调整）
- **宠物信息卡片**：宠物名称（**大两个字号**靠左）+ 宠物状态（**忙碌中/空闲中**，小一个字号靠右）/ 宠物等级（左）+ **当前经验值**（小两号，右，两端对齐）/ **升级进度条**（宽度与等级行相等，含进度百分比，新经验体系「所需经验 = 当前等级 × 100」）/ 宠物属性（**过低的部分红色高亮**：饱食<50 / 口渴<70 / 体力<20 / 心情<50 / 健康<40）
- **打工内容卡片**：打工名称（**大三个字号**靠左）+ **需要消耗的时间**（靠右）/ 工作描述 / **进行本工作的条件**（如有：等级/健康/心情要求）/ **本工作消耗的宠物属性值** / 卡片内分割线 / **报酬（红色 #C00000、文字居右、大一个字号）**
- **玩耍内容卡片**：玩耍名称（大三个字号靠左）+ 需要消耗的时间（靠右）/ 玩耍描述 / 进行本玩耍的条件（如有）/ 卡片内分割线 / **本玩耍变更的宠物属性值**（红色 #C00000、居右、大一个字号，如「经验 +30 · 心情 +20」）
- **卡片高度自适应**（按换行后行数计算，同行取最高），文字自动换行不溢出；**不能打工/玩耍的卡片整体为灰色（#D9D9D9）**——忙碌中、等级/健康/心情不足、属性消耗不足均视为不能

### 宠物指令图片（1.7.1）

发送 `宠物` 时以图片展示，**图片高度随内容自动适应**：

- **图片结构**：`<用户名称> 的宠物` 标题 → **宠物信息卡**（宠物名称大两号 + 状态小一号 / 等级 + 经验值（两端对齐）/ **升级进度条**（含百分比））→ **宠物属性条区** → 分割线 → **底部空闲进度条** + 文字描述
- **宠物属性条**（每个属性：`属性名称 当前值/最大值` + **属性条** + 状态解释）：
  - 属性条高度 = **普通进度条高度的 30%**
  - **颜色**：红色 #C00000（饱食<50 / 口渴<70 / 心情<50 / 体力<20 / 健康<40）；绿色 #92D050（属性与最大值差值 <20 且健康度 ≥41）；灰色 #333333（默认）
  - **状态解释**：仅属性条为红色时显示提示——「宠物饿了 / 渴了 / 不开心 / 累了 / 生病了」，**提示位置固定在整个属性条区域的右侧**（不随属性条填充比例移动）
- **空闲进度条**（图片底部）：
  - **忙碌中**：进度条不满，颜色 **#FFC000**（空白部分无颜色），下方文字 `<宠物名字>正在<打工/玩耍>（剩余 XX）`
  - **空闲**：进度条满，颜色 **#92D050**，下方文字为随机空闲提示句（如「正在晒太阳」「精神饱满」等）；**若存在状态低（红色）条目，则改用第二套提示表示宠物不舒服**（如「看起来不太舒服」「状态不佳」等）

### 商店图片展示

- 道具按**类别分组**（食品/饮料/药物/玩具），类别标题居中 + 分隔线，每行 **`SHOP_CARD_COLS`** 个卡片（默认 3，可在运行参数页调整 2~6）
- 卡片：名称（大三号靠左）+ **已持有数量**（靠右）/ 效果（**空格优先换行**，只有确定会溢出才换行）/ **卡片内分割线** / **价格（红 #C00000、右对齐、大一号、位于分割线与卡片下边界之间，距两端 `SHOP_PRICE_PAD` 像素）**
- 卡片**高度自适应**（同行取最高，被拉伸的低卡片忽略价格与分割线的 N 约束），文字不溢出

### 道具与好感度加成

- `使用 <道具名> [数量]` 使用道具（批量使用时效果按次数累计）；`属性丸` 随机 2 个属性 +5~20（每日最多 3 次）；`农场经验球` 获得升级经验 5%~20%（每日最多 3 次）
- 使用道具时按**好感等级**加成：

| 好感等级 | 正面效果 | 负面效果 |
| --- | --- | --- |
| 0~1 | ×1.0 | ×1.0 |
| 2~5 | ×1.1 | ×1.0 |
| 6~9 | ×1.1 | ×0.9 |
| 10 | ×1.2 | ×0.8 |

## 四、金币银行

| 指令 | 作用 |
| --- | --- |
| `存款 <金额>` | 把钱存进银行，锁定到下一个 4:00 解锁，利息自动发放（不填金额默认存入最大可存金额） |
| `取款 <金额>` | 取出已解锁的本金（不填金额 = 全部取出） |
| `银行统计` | 存款次数 / 生效中存单 / 利息总额 / 最大存储额度 |
| `查询流水` / `流水查询` / `消费记录` | **金币账单**：图片展示金币变动流水（只记发生金额变动的操作） |

- 存款 / 取款 / 银行统计响应均为**图片**
- 金币账单展示最近 **30 条**流水（时间 / 原因 / 变动金额 / 余额）；签到、打工、购买、存款、贷款、农场买卖、红包等所有金币变动都会记入

### 银行贷款（附属于金币银行）

| 指令 | 作用 |
| --- | --- |
| `借款 <套餐代码> <金额>` | 贷款（0=特别强制解锁，1=一般，2=短期，3~10=自定义） |
| `还款 <套餐代码> [金额]` | 还款（不填套餐 = 用全部金币偿还所有贷款，优先还逾期/将到期） |
| `我的贷款` | 查看生效中的贷款账单（图片） |
| `我的征信` | 查看逾期记录 + 生效账单（图片） |

- 贷款功能需先解锁**宠物或农场**（特别贷款除外，见下）
- **特别贷款（套餐 0）**：固定 2500 金币，日息 1%，30 天内还清；选择后自动解锁农场+宠物；逾期则重新上锁并收取仓库价值 10%；还清前不能申请任何贷款
- **一般贷款（套餐 1）**：额度按农场等级（0-10 级 3000 / 11-25 级 10000 / 26-50 级 20000 / 51-75 级 40000 / 76-100 级 100000）；最近 4:00 后开始计息，日息 2%~5% 随机，宠物等级可减免；15 天逾期
- **短期贷款（套餐 2）**：额度按好感度等级（0-2 级 1000 / 3-5 级 2000 / 6-8 级 3000 / 9 级 4000 / 10 级 6000）；10 天免息，之后日息 6%
- **自定义贷款（套餐 3~10）**：管理员在 WebUI「贷款套餐」页配置最大金额 / 好感度等级要求 / 宠物等级要求 / 农场等级要求 / 利息
- 每人每日累计贷款上限 = **2 × 套餐上限**，超出需等次日
- **逾期处置**：还清前不能新增贷款；每日好感度随机降低 1.01~1.25；获得金币自动划扣 20% 还款；每日 23:00 自动卖出仓库道具 + 自动签到抵债；逾期超 30 天农场回退初始；每年最多 4 次逾期，超出禁用贷款功能

### 规则

- **最大存储额度 = 好感度 × 100 + 宠物经验**
- **基础利率**（存钱时按好感度等级随机）：
  - 好感等级 0~3：0.02%~0.10%
  - 好感等级 4~5：0.02%~0.15%
  - 好感等级 6~8：0.05%~0.15%
  - 好感等级 9~10：0.05%~0.18%
- **利率加成**（存钱时按宠物等级随机；无宠物无加成）：
  - 宠物等级 1~10：0.00%~0.01%
  - 宠物等级 11~40：0.00%~0.02%
  - 宠物等级 41~80：0.01%~0.02%
  - 宠物等级 81+：0.01%~0.03%
- **利息 = 本金 ×（基础利率 + 加成）× 计息小时数**（计息时长 = 到**下一个 4:00** 的小时数，向上取整，如 19 小时 45 分算 20 小时；凌晨 0~4 点存款则在当天 4:00 解锁）
- 存款后本金锁定；**下一个 4:00 解锁并停止计息**，利息自动转入金币余额，本金需发送 `取款` 主动取出
- 银行结算为懒结算：玩家签到时自动结算到期的存单，也会在使用存款/取款/银行统计指令时结算

## 五、农场

| 指令 | 作用 |
| --- | --- |
| `解锁农场` | 花 1500 金币解锁农场（赠送 2 块地） |
| `购买土地` | 花 800 金币开垦一块新土地（最多 24 块） |
| `土地升级 <编号>` | 升级土地等级（贫瘠→红→普通→肥沃→黑） |
| `农场商店 [展开] [页码]` | 种子+化肥合并商店（默认：可购种子 9 款 + 不可购 3 款灰卡 + 全部化肥；`展开` 分页显示全部可购种子） |
| `购买 <种子名>种子 [数量]` | 购买种子（**必须带「种子」后缀**，如 `购买 白菜种子 10`；不带后缀视为购买宠物商店商品）；`购买 <化肥名> [数量]` 购买化肥（如 `购买 氮肥`）。快捷指令 `购买种子 <作物名>` / `购买肥料 <肥料名>` 保留 |
| `种植 <作物> [起] [止/数量]` | 种植（不填=种满所有空闲地）；**成功后响应末尾自动附上「土地状态」图片** |
| `使用 <化肥> <数量>` / `施肥 <肥料> [起] [止] [次数]` | 使用化肥（快捷指令 `施肥` 保留） |
| `收割 [编号]` | 收割成熟作物（不填=全部） |
| `取消种植 <编号>` | 取消种植 |
| `土地状态` / `我的农场` | 查看土地与仓库（图片，同效指令） |
| `售卖 [作物] [数量]` / `售卖种子 [种子] [数量]` | 出售作物/种子 |
| `偷菜 <@对方>` | 偷走对方已成熟地块的 10%~20% 产量（按售价得金币，1.7.2） |
| `看家 开` / `看家 关` | 开启/关闭宠物看家防护（需宠物健康度 > 60，1.7.2） |

### 规则

- 农场等级 0~100；**升到 N 级需 1000×N 经验**（收割作物获得经验）
- 每块土地初始为「贫瘠土地」，可依次升级为红(1000)、普通(1500)、肥沃(2000)、黑(3000)，带来产量加成与成熟时间减免
- 种子专属价格随农场等级变化：0~19 级 +50%、20~49 级无加成、50~99 级 -20%、100 级 -30%；种子商店图片里会显示删除线原价 + 红色专属价
- 作物/肥料由管理员在 **WebUI 商店编辑页**编辑（农场商店 → 种子 `作物.txt` / 肥料 `肥料.txt`），增删作物种类、改属性即改即生效
- **农场商店种子卡片**（1.7.2）：种子名称（大三号居左）+ 持有数（居右）/ **购买等级条件（左）+ 作物成熟时间（右）** / **成熟后售价（按贫瘠土地且无肥料状态计算，左）+ 收割农场经验（右）** / 卡片内分割线 / 价格（红 #C00000 右大一号）；不能购买的种子灰卡 #D9D9D9
- **化肥不可出售**：只能购买和使用（施肥），任何情况（含逾期自动卖仓库抵债）都不会被卖出，仓库中标注「不可售」
- **偷菜（1.7.2）**：`偷菜 <@对方>` 偷走对方所有已成熟地块 10%~20% 产量（`STEAL_LOSS_MIN/MAX` 可调），偷菜方按成熟售价得金币；目标作物最低等级 > 偷菜者农场等级 + 5 则失败；被偷方在「土地状态/我的农场/收割」看到偷菜记录（被偷批次收割后 24h 内）；`看家 开` 启用宠物防护（见上「看家」）
- **农场盈利实时结算（允许为负）**（1.7.1）：**盈利 = 售卖作物所获得的金币 − 购买种子所使用的金币 − 购买化肥所使用的金币 − 解锁土地所使用的金币 − 升级土地所使用的金币 − 解锁农场所使用的金币**（售卖种子不计入盈利）
- 土地状态图片中每块土地会标注**升级价格**（已满级显示「已满级」）
- 农场变更（种植/施肥/收割/买卖/升级）后回复会附带**农场当前状态**（等级 / 土地数 / 仓库余量）
- **`土地状态` / `我的农场`**：图片顶部显示**农场属性**——等级、当前经验（含升级所需）、**升级进度条**（含百分比）、**总盈利**（按上述盈利公式实时结算）；下方 **4 列土地卡片**（卡片宽度默认 270 = 原 360 的 75%，可在运行参数页 `FARM_PLOT_CARD_WIDTH` 调整），文字自动换行、卡片高度自适应

## 六、金币红包

| 指令 | 作用 |
| --- | --- |
| `金币红包 <红包个数> <总金额>` | 发红包（出资人为发送者，每人每天最多 4 次） |
| `开` / `开红包` / `抢红包` | 打开当前群所有你能开的红包 |

- 红包**只在当前群聊有效**（红包雨活动红包为**全局红包**，见下文），每位用户**每轮红包只能开一次**
- 红包有效期 **10 分钟**，超时后剩余金额自动退回给发起人
- 金额算法（1.7.1）：**总奖金 = 红包剩余金额，红包个数 = 剩余个数**；个数 = 1 时直接发放剩余金币；否则 **基准奖金 = 总奖金 ÷ 红包个数**，进入加成区判定——**40% 加成区甲**（基准乘区在 **100% ~ (n×100−20)%** 间随机，n 为红包个数）、**60% 加成区乙**（基准乘区在 **20% ~ 100%** 间随机）；**理论奖金 = 基准奖金 × 基准乘区**，按**去尾法**取整、下限 1、上限 总奖金−红包个数−1（保证剩余金额够每个剩余红包至少 1 金币）；发放后剩余金额作为红包池余额、剩余红包数 −1
- 红包被抢完后 **60 秒倒计时**：期间再有人开红包提示「来晚一步，红包被人抢空了～」；若有人发出新红包则取消计时；无红包时提示「本群暂时没有红包」
- 响应均为**图片**，发红包/抢红包/过期退回都会记入金币账单

## 七、活动中心

| 指令 | 作用 |
| --- | --- |
| `活动` | 图片展示当前**正在进行的活动**（每个活动一个卡片、一行一卡） |

- 活动中心是一个**可扩展框架**：管理员在 WebUI「活动中心」页勾选想要激活的活动模块
- 新增活动只需在插件 `activities/` 目录下新建一个 Python 文件（无需改主程序），编写文档见 **`ACTIVITY.md`**

- 活动图片中每个活动为一个**矩形卡片**（活动名称 / 起止时间 / 简介 / 参与要求 / 相关指令），一行一卡
- **活动参数可在 WebUI 直接修改**：每个活动的起止时间 / 简介 / **参与要求（好感度/农场/宠物等级要求大类 + 文字）** / 自定义参数（如双倍签到的「签到倍数」、红包雨的「总金额/个数」），保存后立即生效、重启后保留（详见 `ACTIVITY.md`）

### 定时红包雨（内置活动）

### 运行参数协议（WebUI ↔ 插件）

WebUI「运行参数」页通过以下 API 与插件交互（协议由 `main.py` 中的 `RUNTIME_PARAMS` 描述表驱动，新增参数只需在表中加一项）：

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/astrbot_plugin_signin/params` | `GET` | 返回参数 schema 列表：`{params: [{key, label, type, desc, value, min, max}]}`，前端据此动态渲染表单 |
| `/astrbot_plugin_signin/params` | `POST` | 保存参数：`{params: {key: value}}`；后端按 schema 校验类型与范围，通过后**立即生效**并持久化到 `data.json`，返回 `{saved, applied}` |

- 参数项：`type` 支持 `int` / `float` / `bool` / `string`，`min` / `max` 为校验范围；**格式校验前后端双重把关**——前端保存前校验（空值/非数字/越界红框提示并阻止提交），后端再次校验（类型错误/越界会返回具体原因并**明确标记未生效的参数**，不会静默丢弃），非法值一律不生效
- 参数按**两级折叠菜单**分组展示（一级分组 → 二级子分组）：
  - **撤回设置**：通用（**全局撤回开关** `RECALL_ENABLED`、撤回秒数）、单指令开关（活动/商店/种子商店/肥料商店/帮助）
  - **签到**：金币（签到范围）、**奖池概率**（无奖品 / 属性丸 / 农场经验球抽中概率）
  - **宠物**：解锁、宠物经验、**属性丸**（掉落概率数量 / 提升属性数 / 提升范围 / 每日上限）、玩耍（捡钱概率金额上限）
  - **商店**：宠物商店（每行卡片数）、农场商店（每行卡片数）、通用（价格底边距 N）
  - **金币红包**：发送（每日上限）、有效期
  - **农场**：价格、土地、**卡片显示**（宽度 / 列数）、**农场经验球**（每日上限 / 增加百分比范围）
  - **左轮手枪**：规则、**贷款**：特别贷款、**金币账单**：展示
- 生效方式：直接更新模块全局常量（如 `RECALL_AFTER`），带 `attr` 的参数同时同步插件实例属性（如 `MIN_COINS` → `self.min_coins`），**无需重启插件**
- 持久化：保存在 `plugin_data/astrbot_plugin_signin/data.json` 的 `params` 字段，重启后自动重新应用
- **调试模式**：管理员在对话框发送 `88224646` 解锁 WebUI 顶部的「开启调试模式」按钮（重启后消失）；开启后**数据不写入磁盘**、回复不再转图片（直接发文本）；金币按真实余额增减，**钱不够时发送「加钱」即可获得 50000 金币**（仅调试模式生效）——退出调试模式后自动回到开启前的状态；按钮在重启插件前保留
- **单指令撤回开关（与全局总开关串联）**：运行参数页「撤回设置 → 通用」新增**全局撤回开关** `RECALL_ENABLED`（**默认开启**，总开关）——**关闭时所有消息都不撤回**；开启时按各指令开关决定：「活动」「商店」「种子商店」「肥料商店」及全部**帮助指令**（签到/宠物/农场/左轮手枪/游戏帮助）的回复默认**不撤回**，在运行参数页勾选对应开关（`RECALL_ACTIVITY` / `RECALL_SHOP` / `RECALL_SEED_SHOP` / `RECALL_FERT_SHOP` / `RECALL_HELP`）后即恢复正常撤回，其余指令始终撤回。**串联关系**：总开关开 + 附属开关开 = 撤回；总开关开 + 附属开关关 = 不撤回；总开关关 = 全部不撤回（之前未单独配置撤回开关的指令直接受总开关控制）

## 数据管理（指令方式）

- `查看后台配置`：查看当前 `后台.txt` 内容
- `保存后台配置 <内容>`：用粘贴的全文覆盖 `后台.txt`（先查看再改）
- `导出数据`：把 `data.json` 备份到 `plugin_data/astrbot_plugin_signin/` 下的 `data_export_时间戳.json`，并返回内容（数据大时只给文件路径）
- `导入数据 <JSON>`：用粘贴的 JSON 覆盖 `data.json`；或把 JSON 保存为 `plugin_data/astrbot_plugin_signin/data_import.json` 后直接发送 `导入数据`

## 说明

- 金币、好感度、宠物、战绩均**跨群聊共享**（按用户维度）
- 打工/玩耍有**冷却时间**（1.7.1）：完成后宠物按该项的 `需要时间`（后台.txt 配置）进入冷却，**打工与玩耍共用一个计时器**，冷却期内不能进行新的打工或玩耍
- 属性丸需先解锁宠物才会通过签到获得
- **消息 15 秒后自动撤回**（防刷屏）：插件发出的所有消息（含主动提醒）发送 **15 秒**后撤回；可在 `main.py` 顶部 `RECALL_AFTER` 调整（0 表示不撤回）
- 所有涉及金币变动的回复末尾会显示**当前金币余额**；打工 / 玩耍 / 使用道具的回复末尾会显示**宠物当前状态**

## v1.7.2

### 新增 / 变更

- **偷菜功能（新）**：WebUI 功能开关可单独控制（`偷菜系统`，默认开启）。每位开通农场的用户可对任意开通农场的用户发起偷菜：
  - **指令**：`偷菜 <@对方>` —— 一键偷走对方所有**已成熟**地块的一部分作物（损失当前产量的 10%~20%，`STEAL_LOSS_MIN/MAX` 可调），偷菜方按成熟售价获得金币
  - **基本防御**：目标作物种植最低等级 > 偷菜者农场等级 + 5 → 该作物偷菜失败（「失败：对方等级过低」）
  - **前提**：偷菜者需解锁农场；宠物系统解锁后可用部分功能（看家/护卫）
  - **被偷提示**：被偷方在「我的农场 / 土地状态」图片底部与「收割」回复中看到偷菜信息（无框线表格：`偷菜者|作物 * 数量|损失金额|状态`，列宽自适应、多种作物换行）；成功 #C00000、失败 #7F7F7F、宠物起作用 #BF9000；**有效期 = 被偷批次作物主动收割后 24 小时**
- **看家（宠物防护）**：`看家 开/关` 开启/关闭（需宠物健康度 > `STEAL_GUARD_HEALTH` 默认 60）：
  - **额外保护**：看家生效时偷菜成功额外减少损失 2%~6%（`STEAL_GUARD_REDUCE_MIN/MAX`）
  - **气味记忆**：同一偷菜者 24h 内尝试偷菜超过 `STEAL_SCENT_THRESHOLD`（默认 4）次，对方获得针对该偷菜者的「气味记忆」（记在偷菜者身上），此后该偷菜者再来必被宠物发现，持续 `STEAL_SCENT_HOURS_MIN/MAX`（12~24h）
