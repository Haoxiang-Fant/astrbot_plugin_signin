# astrbot_plugin_signin

一个功能丰富的 AstrBot 群聊娱乐插件，集成了 **签到、左轮手枪、宠物养成** 三大系统。

> 🤖 本插件由 [DeepSeek](https://www.deepseek.com/) 大模型辅助开发完成。
>
> 💡 所有指令**直接发送即可触发，无需前缀或 @ 机器人**；金币、好感度、宠物、战绩等数据**跨群聊共享**（按用户维度）。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 签到 | 金币、好感度、宠物经验、属性丸 |
| 左轮手枪 | 金币下注轮流开枪 |
| 宠物系统 | 养成、每日结算、打工、玩耍、商店 |
| 金币银行 | 存款生息、下一个 4:00 解锁、利息自动入账 |
| 农场 | 解锁土地、种植收割、施肥、售卖、作物/肥料自定义 |

---

## 一、签到

- 发送 `签到` 触发；每天每人限签一次（跨群共享）
- 随机获得 **30~300** 金币、**0.01~1.0** 好感度
- 好感度初始等级为 **0**，每满 **10** 点升 1 级，最高 **10** 级
- 拥有宠物后，签到额外获得 **10~60** 宠物经验，并有 **50%** 概率获得 1~5 个「属性丸」
- 签到时显示宠物每日结算结果与提醒
- `签到` / `我的签到` 响应为**图片**
- `签到帮助`：查看签到模块指令（图片）
- `游戏帮助`：查看全部模块指令（图片，总入口）

## 二、左轮手枪

| 指令 | 作用 |
| --- | --- |
| `装弹 <子弹数> <金币>` | 开局（子弹 1~6） |
| `加入` | 加入本局 |
| `开始` | 发起人提前开始（≥2 人） |
| `开枪` | 轮到你的回合时开枪 |
| `我的战绩` | 胜率 / 净收益 / 谁拿你最多金币 / 你拿谁最多金币 |

- 响应内容均为**图片**（含开局/加入/开枪/战绩等）
- 7 个弹匣随机放 n 发子弹，轮流开枪，中弹者判负
- 失败者扣全部赌注：**双人局手续费 10%**（赢家得 90%），**三人局手续费 5%**（两赢家平分 95%）
- 开局会明确提示**30 秒超时**；超时后若无人加入，主动提醒「超时结束，无事发生」，游戏结束无任何损失

## 三、宠物系统

### 指令

| 指令 | 作用 |
| --- | --- |
| `解锁宠物` | 花 1000 金币领养（每人限一只） |
| `宠物` | 查看属性 / 等级 / 经验 |
| `更改宠物名字 <名字>` | 给宠物起名 |
| `打工` / `打工 <名称>` | 打工列表 / 打工 |
| `玩耍` / `玩耍 <名称>` | 玩耍列表 / 玩耍 |
| `商店` | 查看商品 |
| `购买 <道具名> [数量]` | 购买道具（不填数量 = 1 个） |
| `使用 <道具名> [数量]` | 使用道具（不填数量 = 1 个） |
| `背包` | 查看道具 |
| `宠物帮助` | 玩法总览 |

### 属性与结算

- 宠物属性：饱食度、口渴值、体力、心情值、健康度、经验
- 解锁初始属性：饱食度 100 / 口渴值 100 / 体力 100 / 健康度 120 / 心情值 80 / 经验 0
- 每 **100** 经验升 1 级，最高 **100** 级
- 健康度上限 **200**；饱食/口渴/体力/心情的上限随健康度变化
- **每日零点结算**（懒结算：玩家当日首次操作时自动补结算）：
  - 按健康度档位扣除饱食/口渴，恢复体力，增减心情
  - 按饱食/口渴/心情的「三档」增减健康度
- 结算体力提升 >100 → 提示「休息得很好」；健康度 ≤39 → 提示「生病了」；任意属性第三档 → 提醒照料

### 打工 / 玩耍 / 商店

管理员编辑插件目录下的 **`后台.txt`** 即可自定义（保存后立即生效，无需重启）：

- **打工**：要求（最低等级/健康度/心情值）、消耗（体力/饱食/口渴/健康/心情/时间）、报酬（金币/经验）
- **玩耍**：要求、消耗（体力/饱食/口渴/健康/时间）、报酬（经验/心情值），并有 1% 概率触发「捡到钱了」+100 金币（每个周期最多 2 次）
- **商店**：道具名、类型（食品/饮料/药物/玩具）、价格、各属性效果（可为负数表示负面效果）

### 道具与好感度加成

- `使用 <道具名> [数量]` 使用道具（批量使用时效果按次数累计）；`属性丸` 随机提升全属性 1.0~5.0
- 使用道具时按**好感等级**加成：

| 好感等级 | 正面效果 | 负面效果 |
| --- | --- | --- |
| 0~1 | ×1.0 | ×1.0 |
| 2~5 | ×1.1 | ×1.0 |
| 6~9 | ×1.1 | ×0.9 |
| 10 | ×1.2 | ×0.8 |

## 四、金币银行

| 指令 | 作用 |
| --- | --- |
| `存款 <金额>` | 把钱存进银行，锁定到下一个 4:00 解锁，利息自动发放（不填金额默认存入最大可存金额） |
| `取款 <金额>` | 取出已解锁的本金（不填金额 = 全部取出） |
| `银行统计` | 存款次数 / 生效中存单 / 利息总额 / 最大存储额度 |

- 存款 / 取款 / 银行统计响应均为**图片**

### 银行贷款（附属于金币银行）

| 指令 | 作用 |
| --- | --- |
| `借款 <套餐代码> <金额>` | 贷款（0=特别强制解锁，1=一般，2=短期，3~10=自定义） |
| `还款 <套餐代码> [金额]` | 还款（不填套餐 = 用全部金币偿还所有贷款，优先还逾期/将到期） |
| `我的贷款` | 查看生效中的贷款账单（图片） |
| `我的征信` | 查看逾期记录 + 生效账单（图片） |

- 贷款功能需先解锁**宠物或农场**（特别贷款除外，见下）
- **特别贷款（套餐 0）**：固定 2500 金币，日息 1%，30 天内还清；选择后自动解锁农场+宠物；逾期则重新上锁并收取仓库价值 10%；还清前不能申请任何贷款
- **一般贷款（套餐 1）**：额度按农场等级（0-10 级 3000 / 11-25 级 10000 / 26-50 级 20000 / 51-75 级 40000 / 76-100 级 100000）；最近 4:00 后开始计息，日息 2%~5% 随机，宠物等级可减免；15 天逾期
- **短期贷款（套餐 2）**：额度按好感度等级（0-2 级 1000 / 3-5 级 2000 / 6-8 级 3000 / 9 级 4000 / 10 级 6000）；10 天免息，之后日息 6%
- **自定义贷款（套餐 3~10）**：管理员在 WebUI「贷款套餐」页配置最大金额 / 好感度等级要求 / 宠物等级要求 / 农场等级要求 / 利息
- 每人每日累计贷款上限 = **2 × 套餐上限**，超出需等次日
- **逾期处置**：还清前不能新增贷款；每日好感度随机降低 1.01~1.25；获得金币自动划扣 20% 还款；每日 23:00 自动卖出仓库道具 + 自动签到抵债；逾期超 30 天农场回退初始；每年最多 4 次逾期，超出禁用贷款功能

### 规则

- **最大存储额度 = 好感度 × 100 + 宠物经验**
- **基础利率**（存钱时按好感度等级随机）：
  - 好感等级 0~3：0.02%~0.10%
  - 好感等级 4~5：0.02%~0.15%
  - 好感等级 6~8：0.05%~0.15%
  - 好感等级 9~10：0.05%~0.18%
- **利率加成**（存钱时按宠物等级随机；无宠物无加成）：
  - 宠物等级 1~10：0.00%~0.01%
  - 宠物等级 11~40：0.00%~0.02%
  - 宠物等级 41~80：0.01%~0.02%
  - 宠物等级 81+：0.01%~0.03%
- **利息 = 本金 ×（基础利率 + 加成）× 计息小时数**（计息时长 = 到**下一个 4:00** 的小时数，向上取整，如 19 小时 45 分算 20 小时；凌晨 0~4 点存款则在当天 4:00 解锁）
- 存款后本金锁定；**下一个 4:00 解锁并停止计息**，利息自动转入金币余额，本金需发送 `取款` 主动取出
- 银行结算为懒结算：玩家签到时自动结算到期的存单，也会在使用存款/取款/银行统计指令时结算

## 五、农场

| 指令 | 作用 |
| --- | --- |
| `解锁农场` | 花 1500 金币解锁农场（赠送 2 块地） |
| `购买土地` | 花 800 金币开垦一块新土地（最多 24 块） |
| `土地升级 <编号>` | 升级土地等级（贫瘠→红→普通→肥沃→黑） |
| `种子商店` / `肥料商店` | 查看商店（图片） |
| `购买种子 <作物> <数量>` | 购买种子（受农场等级价格加成影响） |
| `购买肥料 <肥料> <数量>` | 购买肥料 |
| `种植 <作物> [起] [止/数量]` | 种植（不填=种满所有空闲地） |
| `施肥 <肥料> [起] [止] [次数]` | 施肥（不填次数=补满到最大次数） |
| `收割 [编号]` | 收割成熟作物（不填=全部） |
| `取消种植 <编号>` | 取消种植 |
| `土地状态` / `农场仓库` | 查看土地与仓库（图片） |
| `售卖 [作物] [数量]` / `售卖种子 [种子] [数量]` | 出售作物/种子 |

### 规则

- 农场等级 0~100；**升到 N 级需 1000×N 经验**（收割作物获得经验）
- 每块土地初始为「贫瘠土地」，可依次升级为红(1000)、普通(1500)、肥沃(2000)、黑(3000)，带来产量加成与成熟时间减免
- 种子专属价格随农场等级变化：0~19 级 +50%、20~49 级无加成、50~99 级 -20%、100 级 -30%；种子商店图片里会显示删除线原价 + 红色专属价
- 作物/肥料由管理员在 **WebUI 农场后台页**编辑（`作物.txt` / `肥料.txt`），增删作物种类、改属性即改即生效

## 安装

1. 把整个 `astrbot_plugin_signin` 文件夹复制到 AstrBot 插件目录（通常为 `data/plugins/`）
2. 在 AstrBot WebUI「插件」页重新加载并启用
3. 群里发 `签到` 攒金币 → `解锁宠物` → 开始养成

## 文件结构

```
astrbot_plugin_signin/
├── main.py            # 插件主逻辑
├── metadata.yaml      # 插件元数据
├── _conf_schema.json  # WebUI 配置页（可改金币/价格/概率等）
├── OPPOSans-M.ttf     # 图片渲染字体
├── pages/admin/       # WebUI 自定义页（后台.txt/作物/肥料编辑器 + 数据导入导出）
├── 后台.txt            # 管理员配置模板（打工/玩耍/商店）
├── 作物.txt            # 作物配置模板（农场）
├── 肥料.txt            # 肥料配置模板（农场）
├── 贷款套餐.txt        # 自定义贷款套餐模板（代码 3~10）
└── README.md          # 本说明文档
```

> 运行数据（`data.json`、`后台.txt`、`作物.txt`、`肥料.txt`、`贷款套餐.txt`、生成的图片）保存在 AstrBot 的 `plugin_data/astrbot_plugin_signin/` 目录（不再放 plugins 目录）。首次加载会把插件目录里的这些文件自动迁移过去；删除 `plugin_data` 里的 `data.json` 可清空全部数据。

## 自定义配置（WebUI）

插件提供了 **配置页**（`_conf_schema.json`），可在 AstrBot 后台「插件」页直接修改以下设置，无需改代码：

- 签到金币范围（`min_coins` / `max_coins`）
- 宠物解锁价格（`pet_unlock_cost`）
- 签到宠物经验范围（`pet_signin_exp_min` / `pet_signin_exp_max`）
- 属性丸掉落概率与数量（`pill_drop_chance` / `pill_drop_min` / `pill_drop_max`）
- 捡到钱了概率 / 金额 / 每日上限（`money_event_chance` / `money_event_gain` / `money_event_max_per_day`）

> 修改后在后台保存，AstrBot 会自动重新加载插件使配置生效。其余常量仍可在 `main.py` 顶部修改。

## WebUI 页面（Pages）

插件在 `pages/admin/` 下提供了一个后台管理页，可在 AstrBot「插件」页打开插件卡片后进入：

- **后台.txt 编辑器**：在线查看 / 编辑 / 保存打工、玩耍、商店配置，保存即生效
- **数据导入导出**：一键下载 `data.json`；选择本地 JSON 文件上传覆盖导入

> 页面通过 AstrBot 的 `context.register_web_api()` 注册后端 API，前端用 `window.AstrBotPluginPage` bridge 通信。新增/删除页面目录后需重载插件；修改静态资源刷新页面即可。

## 数据管理（指令方式）

- `查看后台配置`：查看当前 `后台.txt` 内容
- `保存后台配置 <内容>`：用粘贴的全文覆盖 `后台.txt`（先查看再改）
- `导出数据`：把 `data.json` 备份到 `plugin_data/astrbot_plugin_signin/` 下的 `data_export_时间戳.json`，并返回内容（数据大时只给文件路径）
- `导入数据 <JSON>`：用粘贴的 JSON 覆盖 `data.json`；或把 JSON 保存为 `plugin_data/astrbot_plugin_signin/data_import.json` 后直接发送 `导入数据`

## 说明

- 金币、好感度、宠物、战绩均**跨群聊共享**（按用户维度）
- 打工/玩耍有**冷却时间**：完成后宠物按该项的 `需要时间`（后台.txt 配置）进入冷却，冷却期内不能再次打工/玩耍（打工与玩耍的冷却相互独立）
- 属性丸需先解锁宠物才会通过签到获得
- **消息 15 秒后自动撤回**（防刷屏）：插件发出的所有消息（含主动提醒）发送 **15 秒**后撤回；可在 `main.py` 顶部 `RECALL_AFTER` 调整（0 表示不撤回）
