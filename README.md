# 签到娱乐系统

一个功能丰富的 AstrBot 群聊娱乐插件（原 `astrbot_plugin_signin`），集成了 **签到、左轮手枪、宠物养成、金币银行、农场、金币红包、活动中心、排行榜** 等系统。

> 🤖 本插件由 [DeepSeek](https://www.deepseek.com/) 大模型辅助开发完成。
>
> 💡 所有指令**直接发送即可触发，无需前缀或 @ 机器人**；金币、好感度、宠物、战绩等数据**跨群聊共享**（按用户维度）。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 签到 | 金币、好感度、宠物经验、属性丸 |
| 左轮手枪 | 金币下注轮流开枪 |
| 宠物系统 | 养成、每日结算、打工、玩耍、商店（分类卡片展示）、虚弱状态与治疗 |
| 金币银行 | 存款生息、下一个 4:00 解锁、利息自动入账 |
| 金币账单 | `查询流水` / `流水查询` / `消费记录`，图片展示金币变动流水 |
| 金币红包 | `金币红包 <个数> <总金额>` 发红包（个数上限 25），`开` / `开红包` 抢红包；动态期望平衡算法（严格守恒、期望恒定） |
| 农场 | 解锁土地、种植收割、施肥、售卖、作物/肥料自定义；快捷指令 `种地`（自动收割+播种+购种）/ `施肥`（自动购买）/ `收获`（收割即售出） |

| 排行榜 | `金币排行` / `宠物排行` / `农场排行`，图片展示前 20 名；本群显示真实昵称、非本群脱敏（首*尾），WebUI 一键同步全群昵称 |
| 同义口令 | WebUI「同义口令」配置词义相近的口令别名，发送别名=发送对应指令（如 `打卡 → 签到`） |
| 局域网开放 | WebUI「设置 → 局域网开放」开启后局域网设备可访问后台（需访问密码，密码哈希存储、仅本地可改），查看访问记录、管理黑名单；私聊机器人「管理网址」获取访问地址 |

## 一、签到

- 发送 `签到` 触发；每天每人限签一次（跨群共享）
- 随机获得 **30~300** 金币、**0.01~1.0** 好感度
- 好感度初始等级为 **0**，每满 **10** 点升 1 级，最高 **10** 级
- 拥有宠物后，签到额外获得 **10~60** 宠物经验；额外奖励池（互斥）：**40% 不送任何东西 / 30% 获得 1~5 个「属性丸」/ 30% 获得 1~5 个「农场经验球」**
- **属性丸**：使用后**随机 2 个属性**获得 **+5~20** 提升，**每日最多 3 次**（可在 WebUI 配置）
- **农场经验球**：使用后获得**升级所需总经验的 5%~20%** 农场经验，**每日最多 3 次**（可在 WebUI 配置）
- **特殊机制**：属性丸对应宠物、农场经验球对应农场；若未开通对应功能，签到获得/使用时**自动转为金币**（每个 10 金币）
- 签到时显示宠物每日结算结果与提醒
- `签到` / `我的签到` 响应为**图片**
- `签到帮助`：查看签到模块指令（图片）
- `游戏帮助`：查看全部模块指令（图片，总入口）

## 二、左轮手枪

| 指令 | 作用 |
| --- | --- |
| `装弹 <子弹数> <金币>` | 开局（子弹 1~6） |
| `加入` | 加入本局 |
| `开始` | 发起人提前开始（≥2 人） |
| `开枪` | 轮到你的回合时开枪 |
| `我的战绩` | 胜率 / 净收益 / 谁拿你最多金币 / 你拿谁最多金币 |

- 响应内容均为**图片**（含开局/加入/开枪/战绩等）
- 7 个弹匣随机放 n 发子弹，轮流开枪，中弹者判负
- 失败者扣全部赌注：**双人局手续费 10%**（赢家得 90%），**三人局手续费 5%**（两赢家平分 95%）
- 开局会明确提示**30 秒超时**；超时后若无人加入，主动提醒「超时结束，无事发生」，游戏结束无任何损失

## 三、宠物系统

### 指令

| 指令 | 作用 |
| --- | --- |
| `解锁宠物` | 花 1000 金币领养（每人限一只） |
| `宠物` | 查看宠物总览（2.0.0 新模板：标题+宠物排行数据 / 预留位（最近一次 打工/玩耍/使用道具 的结果）/ 宠物状态卡片 / 底部双卡） |
| `更改宠物名字 <名字>` | 给宠物起名 |
| `打工` / `打工 <名称>` / `打工 全部` | 打工列表 / 打工（完成后返回宠物总览图，结果合入预留位）；不带参数 = 策略一（可进行最高 6 + 不可进行最低 2，升序，个数可在 WebUI「设置 → 宠物」调整）、`全部` = 策略二（全部显示） |
| `玩耍` / `玩耍 <名称>` / `玩耍 全部` | 玩耍列表 / 玩耍（完成后返回宠物总览图，结果合入预留位）；不带参数 = 策略一、`全部` = 全部显示 |
| `商店` | 查看商品（分类卡片图片） |
| `购买 <道具名> [数量]` | 购买道具（不填数量 = 1 个，最多 999） |
| `使用 <道具名> [数量]` | 使用道具（不填数量 = 1 个，最多 999；使用后返回宠物总览图，结果合入预留位） |
| `背包` | 查看道具 |
| `治疗宠物` | 治疗虚弱宠物（花 500 金币，所有数值恢复 40；**仅虚弱状态可用**） |
| `宠物帮助` | 玩法总览 |

- `宠物` 指令回复为**图片（2.0.0 新模板）**：标题 `<用户昵称>的宠物` + 右侧**宠物排行数据** → **预留位**（最近一次 `打工 / 玩耍 / 使用道具` 的结果，格式 `<宠物名><干了什么><成功/失败>`，红 #C00000；无内容则忽略）→ 分割线 → **宠物状态卡片**（名称/状态/等级/经验/升级进度条 + 五项属性条）→ **底部双卡**：
  - **底部卡片1（宽）**（最近变化时黄色高亮）：最近一次五大状态属性的变化 + **变化原因** + 原打工/玩耍进度条模块
  - **底部卡片2（窄）**（有变动时黄色高亮）：宠物正在进行的工作/玩耍项目 + **金币/经验变化** + **预计完成时间**
- **消息合并（2.0.0）**：`打工 / 玩耍 / 使用道具` 成功后的原文本响应合并进宠物总览图的预留位，直接返回同一张宠物总览图（不再单独发文本）
- 宠物**虚弱**期间宠物系统**重新上锁**：`打工` / `玩耍` / `购买` / `使用` / `看家` 等宠物功能指令被锁定（提示「宠物功能已锁定」），查看类与基础功能不受影响；发送 `治疗宠物` 花 **500 金币**即可重新激活（见「更新日志 · v1.7.5 · 宠物虚弱状态」）

### 属性与结算

- 宠物属性：饱食度、口渴值、体力、心情值、健康度、经验
- 解锁初始属性：饱食度 100 / 口渴值 100 / 体力 100 / 健康度 120 / 心情值 80 / 经验 0
- **升级经验（1.7.1）**：所需经验 = **当前等级 × 100**（Lv.1→2 需 100、Lv.2→3 需 200、Lv.3→4 需 300…），最高 **100** 级；**旧数据按宠物经验总值自动匹配新等级体系**
- 健康度上限 **200**；饱食/口渴/体力/心情的上限随健康度变化
- **每日零点结算**（懒结算：玩家当日首次操作时自动补结算）：
  - 按健康度档位扣除饱食/口渴，恢复体力，增减心情
  - 按饱食/口渴/心情的「三档」增减健康度
- 结算体力提升 >100 → 提示「休息得很好」；健康度 ≤39 → 提示「生病了」；任意属性第三档 → 提醒照料
- **虚弱状态（1.7.5）**：宠物**连续两天结算后健康值均为 0** → 进入「虚弱」状态（宠物卡与状态摘要显示 😷 虚弱标记），同时宠物系统**重新上锁**——`打工` / `玩耍` / `购买` / `使用` / `看家` 被锁定（提示「宠物功能已锁定」），查看类与基础功能不受影响；发送 `治疗宠物` 花 **500 金币**即可重新激活：所有数值恢复为 **40** 并解除虚弱（**只有虚弱状态的宠物才能治疗**，健康一经恢复则连零计数中断）

### 打工 / 玩耍 / 商店

管理员编辑插件目录下的 **`后台.txt`** 即可自定义（保存后立即生效，无需重启）：

- **打工**：要求（最低等级/健康度/心情值）、消耗（体力/饱食/口渴/健康/心情/时间）、报酬（金币/经验）
- **玩耍**：要求、消耗（体力/饱食/口渴/健康/时间）、报酬（经验/心情值，可另配 **`体力=`** / **`健康度=`** 收益字段——如 `健康度=2` 表示玩耍额外增加 2 健康、`健康度=-3` 表示扣 3 健康），并有 1% 概率触发「捡到钱了」+100 金币（每个周期最多 2 次）；红字按**净变化**显示健康（收益 − 消耗，可为负）
- **商店**：道具名、类型（食品/饮料/药物/玩具）、价格、各属性效果（可为负数表示负面效果）
- 打工/玩耍完成后宠物按该项的 `需要时间` 进入**冷却**，**打工与玩耍共用一个计时器**：冷却期内不能进行新的打工或玩耍（1.7.1）
- **消耗字段名兼容**：健康消耗支持 `消耗健康度` / `消耗健康值` / `消耗健康` 任意写法（如 `消耗健康值=5`），其余消耗字段为 `消耗体力` / `消耗饱食度` / `消耗口渴值` / `消耗心情值`

### 打工 / 玩耍列表图片（1.7.1 布局）

发送 `打工` / `玩耍` 时以图片展示，**图片高度随内容自动适应**：

- **图片结构**：`<用户名称>` 标题 → **宠物信息卡片**（横跨整行，宽度 = 下方内容卡片一行布局总宽度）→ 分割线 → **打工/玩耍内容卡片**（每行 `WORK_CARD_COLS` / `PLAY_CARD_COLS` 个，默认 2，可在运行参数页调整 1~4；卡片宽度默认 **522 = 原 290 的 180%**，可在运行参数页 `WORK_PLAY_CARD_WIDTH` 调整）
- **宠物信息卡片**：宠物名称（**大两个字号**靠左）+ 宠物状态（**忙碌中/空闲中**，小一个字号靠右）/ 宠物等级（左）+ **当前经验值**（小两号，右，两端对齐）/ **升级进度条**（宽度与等级行相等，含进度百分比，新经验体系「所需经验 = 当前等级 × 100」）/ 宠物属性（**过低的部分红色高亮**：饱食<50 / 口渴<70 / 体力<20 / 心情<50 / 健康<40）
- **打工内容卡片**：打工名称（**大三个字号**靠左）+ **需要消耗的时间**（靠右）/ 工作描述 / **进行本工作的条件**（如有：等级/健康/心情要求）/ **本工作消耗的宠物属性值** / 卡片内分割线 / **报酬（红色 #C00000、文字居右、大一个字号）**
- **玩耍内容卡片**：玩耍名称（大三个字号靠左）+ 需要消耗的时间（靠右）/ 玩耍描述 / **「要求（条件）」下一行显示需要的 饱食度/口渴值/体力/健康度（中文全称，如 `需要：饱食度 30 口渴值 20 体力 40 健康度 5`，无消耗显示 `需要：无`）** / 卡片内分割线 / **玩耍收益（红色 #C00000、居右、大一个字号：经验、心情与健康净变化，不含体力）**，如「经验 +20 · 心情 +15 · 健康 -3」——**红字不一定是正收益，扣健康的项目显示负数**
- **卡片高度自适应**（按换行后行数计算，同行取最高），文字自动换行不溢出；**不能打工/玩耍的卡片整体为灰色（#D9D9D9）**——忙碌中、等级/健康/心情不足、属性消耗不足均视为不能

### 宠物指令图片（1.7.1）

发送 `宠物` 时以图片展示，**图片高度随内容自动适应**：

- **图片结构**：`<用户名称> 的宠物` 标题 → **宠物信息卡**（宠物名称大两号 + 状态小一号 / 等级 + 经验值（两端对齐）/ **升级进度条**（含百分比））→ **宠物属性条区** → 分割线 → **底部空闲进度条** + 文字描述
- **宠物属性条**（每个属性：`属性名称 当前值/最大值` + **属性条** + 状态解释）：
  - 属性条高度 = **普通进度条高度的 30%**
  - **颜色**：红色 #C00000（饱食<50 / 口渴<70 / 心情<50 / 体力<20 / 健康<40）；绿色 #92D050（属性与最大值差值 <20 且健康度 ≥41）；灰色 #333333（默认）
  - **状态解释**：仅属性条为红色时显示提示——「宠物饿了 / 渴了 / 不开心 / 累了 / 生病了」，**提示位置固定在整个属性条区域的右侧**（不随属性条填充比例移动）
- **空闲进度条**（图片底部）：
  - **忙碌中**：进度条不满，颜色 **#FFC000**（空白部分无颜色），下方文字 `<宠物名字>正在<打工/玩耍>（剩余 XX）`
  - **空闲**：进度条满，颜色 **#92D050**，下方文字为随机空闲提示句（如「正在晒太阳」「精神饱满」等）；**若存在状态低（红色）条目，则改用第二套提示表示宠物不舒服**（如「看起来不太舒服」「状态不佳」等）

### 商店图片展示

- 道具按**类别分组**（食品/饮料/药物/玩具），类别标题居中 + 分隔线，每行 **`SHOP_CARD_COLS`** 个卡片（默认 3，可在运行参数页调整 2~6）；**大标题下方显示金币余额（1.7.6）**
- 卡片：名称（大三号靠左）+ **已持有数量**（靠右）/ 效果（**空格优先换行**，只有确定会溢出才换行）/ **卡片内分割线** / **价格（红 #C00000、右对齐、大一号、位于分割线与卡片下边界之间，距两端 `SHOP_PRICE_PAD` 像素）**
- 卡片**高度自适应**（同行取最高，被拉伸的低卡片忽略价格与分割线的 N 约束），文字不溢出

## 四、金币银行

| 指令 | 作用 |
| --- | --- |
| `存款 <金额>` | 把钱存进银行，锁定到下一个 4:00 解锁，利息自动发放（不填金额默认存入最大可存金额） |
| `取款 <金额>` | 取出已解锁的本金（不填金额 = 全部取出） |
| `银行统计` | 存款次数 / 生效中存单 / 利息总额 / 最大存储额度 |
| `查询流水` / `流水查询` / `消费记录` | **金币账单**：图片展示金币变动流水（只记发生金额变动的操作） |

- 存款 / 取款 / 银行统计响应均为**图片**
- 金币账单展示最近 **30 条**流水（时间 / 原因 / 变动金额 / 余额）；签到、打工、购买、存款、贷款、农场买卖、红包等所有金币变动都会记入

### 银行贷款（附属于金币银行）

| 指令 | 作用 |
| --- | --- |
| `借款 <套餐代码> <金额>` | 贷款（0=特别强制解锁，1=一般，2=短期，3~10=自定义） |
| `还款 <套餐代码> [金额]` | 还款（不填套餐 = 用全部金币偿还所有贷款，优先还逾期/将到期） |
| `我的贷款` | 查看生效中的贷款账单（图片） |
| `我的征信` | 查看逾期记录 + 生效账单（图片） |

- 贷款功能需先解锁**宠物或农场**（特别贷款除外，见下）
- **特别贷款（套餐 0）**：固定 2500 金币，日息 1%，30 天内还清；选择后自动解锁农场+宠物；逾期则重新上锁并收取仓库价值 10%；还清前不能申请任何贷款
- **一般贷款（套餐 1）**：额度按农场等级（0-10 级 3000 / 11-25 级 10000 / 26-50 级 20000 / 51-75 级 40000 / 76-100 级 100000）；最近 4:00 后开始计息，日息 2%~5% 随机，宠物等级可减免；15 天逾期
- **短期贷款（套餐 2）**：额度按好感度等级（0-2 级 1000 / 3-5 级 2000 / 6-8 级 3000 / 9 级 4000 / 10 级 6000）；10 天免息，之后日息 6%
- **自定义贷款（套餐 3~10）**：管理员在 WebUI「贷款套餐」页配置最大金额 / 好感度等级要求 / 宠物等级要求 / 农场等级要求 / 利息
- 每人每日累计贷款上限 = **2 × 套餐上限**，超出需等次日
- **逾期处置**：还清前不能新增贷款；每日好感度随机降低 1.01~1.25；获得金币自动划扣 20% 还款；每日 23:00 自动卖出仓库道具 + 自动签到抵债；逾期超 30 天农场回退初始；每年最多 4 次逾期，超出禁用贷款功能

### 规则

- **最大存储额度 = 好感度 × 100 + 宠物经验**
- **基础利率**（存钱时按好感度等级随机）：
  - 好感等级 0~3：0.02%~0.10%
  - 好感等级 4~5：0.02%~0.15%
  - 好感等级 6~8：0.05%~0.15%
  - 好感等级 9~10：0.05%~0.18%
- **利率加成**（存钱时按宠物等级随机；无宠物无加成）：
  - 宠物等级 1~10：0.00%~0.01%
  - 宠物等级 11~40：0.00%~0.02%
  - 宠物等级 41~80：0.01%~0.02%
  - 宠物等级 81+：0.01%~0.03%
- **利息 = 本金 ×（基础利率 + 加成）× 计息小时数**（计息时长 = 到**下一个 4:00** 的小时数，向上取整，如 19 小时 45 分算 20 小时；凌晨 0~4 点存款则在当天 4:00 解锁）
- 存款后本金锁定；**下一个 4:00 解锁并停止计息**，利息自动转入金币余额，本金需发送 `取款` 主动取出
- 银行结算为懒结算：玩家签到时自动结算到期的存单，也会在使用存款/取款/银行统计指令时结算

### 规则

- 农场等级 0~100；**升到 N 级需 1000×N 经验**（收割作物获得经验）
- 每块土地初始为「贫瘠土地」，可依次升级为红(1000)、普通(1500)、肥沃(2000)、黑(3000)，带来产量加成与成熟时间减免
- 种子专属价格随农场等级变化：0~19 级 +50%、20~49 级无加成、50~99 级 -20%、100 级 -30%；种子商店图片里会显示删除线原价 + 红色专属价
- 作物/肥料由管理员在 **WebUI 商店编辑页**编辑（农场商店 → 种子 `作物.txt` / 肥料 `肥料.txt`），增删作物种类、改属性即改即生效；2.0.0 起化肥属性为：**价格(金币/小时) / 增产%/次 / 可加速次数**（`-1` = 不限，替代旧版「最大使用次数」）
- **作物成长阶段（2.0.0）**：管理员可在 WebUI「设置 → 农场 → 成长阶段」编辑作物等级划分与各等级阶段数——按贫瘠土地上的成熟分钟数把作物分为 1~4 级（默认 `0-240 / 241-480 / 481-720 / 721-1440` 分钟），各级成长阶段数默认 `4 / 5 / 5 / 6`；作物的总生长周期被均分为对应数量的阶段，**化肥每次加速推进一个阶段**
- **化肥加速限制（2.0.0）**：`理论最大使用时间 = 可加速次数 × 每阶段时间`；`实际可用时间 = 剩余可加速完整阶段次数 × 阶段时间 + 残余阶段总时间`，且满足「当前所用时间 + 实际可用时间 ≤ 当前土地上的最大生长时间」；化肥按小时购买、按分钟使用（`施肥 <化肥> <编号> <分钟>`，`使用 <化肥> <分钟>`）
- **农场商店种子卡片**（1.7.2）：种子名称（大三号居左）+ 持有数（居右）/ **购买等级条件（左）+ 作物成熟时间（右）** / **成熟后售价（按贫瘠土地且无肥料状态计算，左）+ 收割农场经验（右）** / 卡片内分割线 / 价格（红 #C00000 右大一号）；不能购买的种子灰卡 #D9D9D9
- **化肥不可出售**：只能购买和使用（施肥），任何情况（含逾期自动卖仓库抵债）都不会被卖出，仓库中标注「不可售」
- **偷菜（2.0.1 重做）**：`偷菜 <@对方>` 偷走对方每个已成熟地块当前产量的 **5%~20%**（`STEAL_LOSS_MIN/MAX` 可调），偷菜方按成熟售价得金币、农场主损失对应数量；目标作物最低等级 > 偷菜者农场等级 + 5 该地块失败；**保护地块**——地块当前产量低于原始产量 × `STEAL_PROTECT_RATIO`（默认 50%）即「被偷完了」，剩余作物不可再被偷；**农场等级差**——目标农场等级 ≥ 偷菜者 + `STEAL_LEVEL_GAP`（默认 10）无法偷菜；**宠物加护**（农场主宠物激活且空闲、状态档位 1-2）：10%「抓到你了」偷菜失败 + 偷菜者获气味记忆 24h + 主人体力 −2~5；20%「给我站住」农场主损失减半 + 偷菜者缴原金额 110% 罚款 + 主人体力 −3~6 + 该农场主 12h 等级压制失效；宠物等级压制（主宠比偷菜者宠高 ≥10 级 → 加护概率减半）；**气味记忆**——同偷菜者对同农场主连续成功 3 次（24h 内）触发，24h 内该农场主加护概率 ×3 且不受压制影响；被偷方在「土地状态/我的农场/收割」看到偷菜记录；全部参数在 WebUI「设置 → 偷菜」调整
- **农场盈利实时结算（允许为负）**（1.7.1）：**盈利 = 售卖作物所获得的金币 − 购买种子所使用的金币 − 购买化肥所使用的金币 − 解锁土地所使用的金币 − 升级土地所使用的金币 − 解锁农场所使用的金币**（售卖种子不计入盈利）
- 土地状态图片中每块土地会标注**升级价格**（已满级显示「已满级」）
- **农场响应整合（2.0.0）**：农场指令（售出/种植/施肥/收割/开垦/升级等）回复统一为**一张纯图片**（不再文本+图片）——标题行显示 `<用户名>的农场` 与**农场排行榜排行积分**；盈利行显示**总盈利 + 本次盈利变化**（支出 `-`、收入 `+` 且显示具体金额）；等级展示模块 → 分割线 → **土地卡片区**（**黄 #FFE699 = 种植变化 / 红 #FFC5C5 = 收割变化 / 蓝 #B4C7E7 = 开垦·施肥·升级变化**，高亮变化不再作文本提示）；图片底部为**大卡片**（宽度 = 同一行土地卡片宽度+间距总和），展示**自动化行为提示**（购买/使用/售出了什么）与**金币变化**
- **`土地状态` / `我的农场`**：图片顶部显示**农场属性**——等级、当前经验（含升级所需）、**升级进度条**（含百分比）、**总盈利**（按上述盈利公式实时结算）；下方 **4 列土地卡片**（卡片宽度默认 270 = 原 360 的 75%，可在运行参数页 `FARM_PLOT_CARD_WIDTH` 调整），文字自动换行、卡片高度自适应

## 六、金币红包

| 指令 | 作用 |
| --- | --- |
| `金币红包 <红包个数> <总金额>` | 发红包（出资人为发送者，每人每天最多 4 次） |
| `开` / `开红包` / `抢红包` | 打开当前群所有你能开的红包 |

- 红包**只在当前群聊有效**（红包雨活动红包为**全局红包**，见下文），每位用户**每轮红包只能开一次**；**红包个数上限 25**
- 红包有效期 **10 分钟**，超时后剩余金额自动退回给发起人
- 金额算法（1.7.5，动态期望平衡算法）：**总奖金 = 红包剩余金额，红包个数 = 剩余个数**；个数 = 1 时直接发放剩余金币；否则——
  - 全部按**整数（分）**计算；**绝对守恒**：全量发放后所有用户实得之和严格等于红包初始总额（误差 0）
  - **顺序无偏**：任意时刻抢得金额的数学期望恒等于 `剩余总额 ÷ 剩余个数`
  - **安全上限** `MAX = 剩余总额 − (剩余个数 − 1)`（为剩余每人预留至少 1）；**基准奖金** `base = 剩余总额 ÷ 剩余个数`（向下取整）
  - 高暴击区 A：倍率随机在 `[1.5, min(3.0, MAX ÷ base)]`（区间无效则该份不暴击）；普通区 B：倍率随机在 `[0.5, 1.3]`（期望 0.9）
  - 按「期望恒定」**动态反推进入 A 区的概率**（`P_A = 0.1 ÷ (E_A − 0.9)`，最高截断 0.6 防失衡）；去尾取整后截断到 `[1, MAX]`
  - 发放后剩余金额作为红包池余额、剩余红包数 −1（并发安全由插件全局锁保证，读取→扣减→写回串行原子）
- 红包被抢完后 **60 秒倒计时**：期间再有人开红包提示「来晚一步，红包被人抢空了～」；若有人发出新红包则取消计时；无红包时提示「本群暂时没有红包」
- 响应均为**图片**，发红包/抢红包/过期退回都会记入金币账单

- **进度条**：占「用户名」与「积分」之间的空间；**第一名恒为 100%**，其它名次进度 = `该用户积分 ÷ 第一名积分`；**进度条左侧留白 = 原先的 200%**（`RANK_BAR_GAP_LEFT_MULT`）、**右侧留白 = 原先的 300%**（`RANK_BAR_GAP_RIGHT_MULT`）
- **行间分割线**：颜色 **`#D9D9D9`**（`RANK_SEP_COLOR` 可调），每一行之间分开、只出现在 **用户名 / 进度条 / 积分** 下方（不覆盖名次列），**高度 = 原先的 30%**（行高 × `RANK_ROW_SEP_PCT`，默认 0.03），紧跟文字行底、**文字与分割线距离对所有行一致**
- **全局排行榜 + 群成员脱敏**：榜单统计全服玩家；**在本群**的用户显示**本群昵称**，**非本群用户**显示**脱敏后的昵称**（「第一个字 \* 最后一个字」，如 `张三` → `张*三`、`李四明` → `李*明`），**绝不用 `***`**；多群昵称不一致时随机取一个群的昵称再脱敏
- **本群判定（以 WebUI 同步名单为准）**：通过后台管理页「**群昵称同步**」一键拉取的昵称数据（`data.json → group_names`）确定**每个群都有哪些用户、以及用户在不同群的昵称**；查询排行榜时，**在本群**的用户显示**本群昵称**，**不在本群**的用户显示**脱敏后的昵称**（兼容 48h 活跃标记 `group_members`：未同步/刚加入的群也能识别本群用户）
- **脱敏措施（绝不用 `***`）**：非本群用户显示为「**昵称第一个字 \* 昵称最后一个字**」（如 `李四明` → `李*明`、`张三` → `张*三`）；完全没有昵称信息（兜底只剩用户 ID）时按用户 ID 同样「首\*尾」脱敏（如 `123456` → `1*6`）
- **脱敏字段选择**：取该用户昵称时，**若其在多个群的昵称不一致，则随机选择一个昵称再做脱敏**；昵称一致的群直接使用
- **本群成员注册机制（兼容层）**：用户在本群触发插件任一功能即标记（48h 有效，`GROUP_MEMBER_TTL_HOURS` 可调），并在每次查榜时通过平台 API 刷新在榜用户的本群昵称；标记在响应前完成，用户首次查询排行榜即能显示正确昵称；私聊查询时全员按非本群处理（旧数据自动兼容）

### 排行积分计算规则

- **金币排行**：`持有金币 × 1.0 + 银行存款 × 1.0`（银行存款 = 所有存单本金之和，含锁定与已解锁未取出的部分）
- **宠物排行**：`宠物经验 × 2.0 + 宠物健康度 × 1.5 +（饱食度+口渴值+体力+心情值）× 0.5`（只统计已解锁宠物的用户）
- **农场排行**：`农场经验 × 2.0 +（拥有土地数 - 2）× 400 + 土地等级分合计 × 0.5`（只统计已解锁农场的用户）
- **土地等级分**：按每块土地**累计升级花费**计分——贫瘠 0 分 / 红土地 1000 分 / 普通土地 2500 分 / 肥沃土地 4500 分 / 黑土地 7500 分，每块地块单独计算后求和（分数表 `RANK_PLOT_SCORES` 可调）
- 积分相同按用户 ID 稳定排序；未解锁对应系统的用户不参与该榜

### WebUI 适配

所有可调参数都可在插件后台「**运行参数 → 排行榜**」页调整，保存后立即生效、无需重启：

- **通用**：展示名次（`RANK_DISPLAY`，默认 20）/ 我的名次高亮颜色（`RANK_HIGHLIGHT_COLOR`，默认 `#92D050`）/ 普通行文字颜色（`RANK_TEXT_COLOR`，默认 `#000000`）/ 脱敏行文字颜色（`RANK_MASKED_COLOR`，默认 `#7F7F7F`）/ **分割线颜色**（`RANK_SEP_COLOR`，默认 `#D9D9D9`）/ **图片宽度倍数**（`RANK_IMAGE_SCALE`，默认 2.5）/ **进度条颜色浅化比例**（`RANK_BAR_LIGHTEN`，默认 0.2）/ **名字显示最大字符数**（`RANK_NAME_MAX_CHARS`，默认 6，超出用 `...`）/ **进度条左侧留白倍数**（`RANK_BAR_GAP_LEFT_MULT`，默认 2.0 = 200%）/ **进度条右侧留白倍数**（`RANK_BAR_GAP_RIGHT_MULT`，默认 3.0 = 300%）/ **行分割线高度占比**（`RANK_ROW_SEP_PCT`，默认 0.03 = 原先的 30%）/ **群成员标记有效期**（`GROUP_MEMBER_TTL_HOURS`，默认 48 小时）
- **金币排行**：金币权重 / 银行存款权重（默认均为 1.0）
- **宠物排行**：经验权重（2.0）/ 健康度权重（1.5）/ 其它属性权重（0.5）
- **农场排行**：经验权重（2.0）/ 土地数权重（400.0）/ 土地等级分权重（0.5）/ **土地等级分表**（`RANK_PLOT_SCORES`，逗号分隔，默认 `0,1000,2500,4500,7500`）

## WebUI 页面（Pages）

插件在 `pages/admin/` 下提供了一个后台管理页，可在 AstrBot「插件」页打开插件卡片后进入：

- **商店编辑**（1.7.3）：统一管理所有商店类配置——**宠物商店**（按类型拆分：食物 / 饮料 / 药物 / 玩具 独立折叠编辑，对应 `宠物商店-食物.txt` 等）/ **农场商店 → 种子**（`作物.txt`）/ **农场商店 → 肥料**（`肥料.txt`），保存即生效
- **打工玩耍**：编辑 `后台.txt`（打工 / 玩耍，1.7.3 起不再含商店段落）
- **功能开关**（1.7.3）：逐系统开关——农场 / 签到 / 活动 / 宠物 / 金币红包 / 银行贷款 / 银行储蓄 / **偷菜**，关闭后对应指令提示「功能已被管理员关闭」，默认全部开启

- **活动中心**：勾选启用 / 停用活动模块，并直接编辑每个活动的参数（如红包雨的**单轮总金额 / 红包个数 / 开启时间 / 有效期**、双倍签到的**签到倍数**），保存立即生效（活动组件编写见 `ACTIVITY.md`）
- **同义口令**：配置**词义相近的口令别名**（发送别名 = 发送对应指令，如 `打卡 → 签到`、`存金币 → 存款`、`治疗 → 治疗宠物`），目标指令从标准指令列表下拉选择，可自由增删改，保存立即生效
- **群昵称同步**：一键拉取**所有群聊**的成员昵称（`get_group_list` → `get_group_member_list`，card 优先、nickname 回落）存入 `data.json → group_names`，作为排行榜**本群判定与默认昵称的唯一事实来源**（本群显示真名、非本群按「首*尾」脱敏）
- **数据导入导出**：一键导出**全部数据**（`data.json` 存档 + 后台.txt / 宠物商店-*.txt / 作物.txt / 肥料.txt / 贷款套餐.txt 自定义配置，打包为单个 JSON）；导入时一并还原以上全部文件（兼容旧版仅 data.json 的导出）

### 运行参数协议（WebUI ↔ 插件）

WebUI「运行参数」页通过以下 API 与插件交互（协议由 `main.py` 中的 `RUNTIME_PARAMS` 描述表驱动，新增参数只需在表中加一项）：

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/astrbot_plugin_signin/params` | `GET` | 返回参数 schema 列表：`{params: [{key, label, type, desc, value, min, max}]}`，前端据此动态渲染表单 |
| `/astrbot_plugin_signin/params` | `POST` | 保存参数：`{params: {key: value}}`；后端按 schema 校验类型与范围，通过后**立即生效**并持久化到 `data.json`，返回 `{saved, applied}` |

- 参数项：`type` 支持 `int` / `float` / `bool` / `string` / `list`（逗号分隔多个数值，如 `FARM_UPGRADE_COSTS` / `LOAN_FAV_DROP_SPECIAL` / `LOAN_AUTO_TIME`），`min` / `max` 为校验范围；**格式校验前后端双重把关**——前端保存前校验（空值/非数字/越界红框提示并阻止提交），后端再次校验（类型错误/越界会返回具体原因并**明确标记未生效的参数**，不会静默丢弃），非法值一律不生效
- 参数按**两级折叠菜单**分组展示（一级分组 → 二级子分组）：
  - **撤回设置**：通用（**全局撤回开关** `RECALL_ENABLED`、撤回秒数）、单指令开关（活动/商店/种子商店/肥料商店/帮助）
  - **签到**：金币（签到范围）、**奖池概率**（无奖品 / 属性丸 / 农场经验球抽中概率）、**好感度**（签到最少/最多好感度、最高等级、每级所需点数）
  - **宠物**：解锁、宠物经验、**属性丸**（掉落概率数量 / 提升属性数 / 提升范围 / 每日上限 / 道具名 / 转金币单价）、属性（健康度上限）、玩耍（捡钱概率金额上限）、打工玩耍（卡片数 / 宽度）
  - **商店**：宠物商店（每行卡片数）、农场商店（每行卡片数）、通用（价格底边距 N）
  - **金币红包**：发送（每日上限）、有效期（红包雨参数已迁移至「活动中心」，见七、活动中心）
  - **农场**：价格、土地（最大数量 / 升级费用 / 农场最大等级 / 升级经验基数 / 赠送土地数）、**卡片显示**（宽度 / 列数）、**农场经验球**（每日上限 / 增加百分比范围 / 道具名）
  - **左轮手枪**：规则（弹匣 / 子弹上限 / 玩家人数 / 加入超时 / 手续费）
  - **贷款**：特别贷款（金额 / 日息 / 限期 / 逾期收取比例）、规则（自动扣款比例 / 好感度降低范围 / 逾期次数上限 / 逾期天数 / 免息天数 / 短期利率 / 每日倍数 / 农场回退天数 / 自动处理时间）
  - **偷菜**：规则（损失比例上下限 / 保护地块产量阈值 / 农场等级差限制）、宠物加护（概率 / 主人体力下降 / 罚款比例 / 等级压制失效时长 / 压制级差与除数 / 加护失效状态档位）、气味记忆（连续成功次数 / 持续时长 / 概率倍数）、自动偷菜（每日成功次数 / 目标数）
  - **金币账单**：展示（条数）
  - **调试**：口令、图片（临时图片保留秒数）
- 生效方式：直接更新模块全局常量（如 `RECALL_AFTER`），带 `attr` 的参数同时同步插件实例属性（如 `MIN_COINS` → `self.min_coins`），**无需重启插件**
- 持久化：保存在 `plugin_data/astrbot_plugin_signin/data.json` 的 `params` 字段，重启后自动重新应用
- **调试模式**：管理员在对话框发送 `88224646` 解锁 WebUI 顶部的「开启调试模式」按钮（重启后消失）；开启后**数据不写入磁盘**、回复不再转图片（直接发文本）；金币按真实余额增减，**钱不够时发送「加钱」即可获得 50000 金币**（仅调试模式生效）——退出调试模式后自动回到开启前的状态；按钮在重启插件前保留
- **单指令撤回开关（与全局总开关串联）**：运行参数页「撤回设置 → 通用」新增**全局撤回开关** `RECALL_ENABLED`（**默认开启**，总开关）——**关闭时所有消息都不撤回**；开启时按各指令开关决定：「活动」「商店」「种子商店」「肥料商店」及全部**帮助指令**（签到/宠物/农场/左轮手枪/游戏帮助）的回复默认**不撤回**，在运行参数页勾选对应开关（`RECALL_ACTIVITY` / `RECALL_SHOP` / `RECALL_SEED_SHOP` / `RECALL_FERT_SHOP` / `RECALL_HELP`）后即恢复正常撤回，其余指令始终撤回。**串联关系**：总开关开 + 附属开关开 = 撤回；总开关开 + 附属开关关 = 不撤回；总开关关 = 全部不撤回（之前未单独配置撤回开关的指令直接受总开关控制）

## 数据管理（指令方式）

- `查看后台配置`：查看当前 `后台.txt` 内容
- `保存后台配置 <内容>`：用粘贴的全文覆盖 `后台.txt`（先查看再改）
- `导出数据`：把 `data.json` 备份到 `plugin_data/astrbot_plugin_signin/` 下的 `data_export_时间戳.json`，并返回内容（数据大时只给文件路径）
- `导入数据 <JSON>`：用粘贴的 JSON 覆盖 `data.json`；或把 JSON 保存为 `plugin_data/astrbot_plugin_signin/data_import.json` 后直接发送 `导入数据`

## 说明

- 金币、好感度、宠物、战绩均**跨群聊共享**（按用户维度）
- 打工/玩耍有**冷却时间**（1.7.1）：完成后宠物按该项的 `需要时间`（后台.txt 配置）进入冷却，**打工与玩耍共用一个计时器**，冷却期内不能进行新的打工或玩耍
- 属性丸需先解锁宠物才会通过签到获得
- **消息 15 秒后自动撤回**（防刷屏）：插件发出的所有消息（含主动提醒）发送 **15 秒**后撤回；可在 `main.py` 顶部 `RECALL_AFTER` 调整（0 表示不撤回）
- 所有涉及金币变动的回复末尾会显示**当前金币余额**；打工 / 玩耍 / 使用道具的回复末尾会显示**宠物当前状态**

  - **宠物属性条**（每个属性：`属性名称 当前值/最大值` + 属性条 + 状态解释）：属性条高度 = **普通进度条的 30%**；颜色规则——红色 #C00000（饱食<50 / 口渴<70 / 心情<50 / 体力<20 / 健康<40）、绿色 #92D050（与最大值差值<20 且健康度≥41）、灰色 #333333（默认）；仅红色时在属性条空白右侧显示状态解释（宠物饿了/渴了/不开心/累了/生病了）。

## v1.7.0

### 新增

- **消息自动撤回修复**：插件发出的所有消息（含主动提醒）发送 **15 秒**后自动撤回。发送改为走适配器底层接口以可靠获取 `message_id`（aiocqhttp/OneBot v11 使用 `event.bot.api.call_action` 直发，图片转 base64；QQ 官方使用 `send_by_session`），撤回优先调用 `event.bot.delete_msg` 与 botpy 原生接口，失败时再以平台/事件兜底，撤回不再失效。可在 `main.py` 顶部 `RECALL_AFTER` 调整（设为 0 则不撤回）。

- **农场商店改版**：种子与化肥合并为一张商店图展示（发送「农场商店」），**完全套用商店卡片模板**——类别标题居中 + 居中分隔线，卡片：名称（大三号）+ 持有数 / **等级条件**（如有）/ **成熟后售价（按一块贫瘠土地且无肥料状态计算）+ 收割农场经验**（空格优先换行）/ 卡片内分割线 / 红色右对齐价格（贴底边 N 像素）；**不可购买的种子以灰卡（#D9D9D9）标记**；每行 **`FARM_SHOP_COLS`** 个卡片（默认 4，可调整）。卡片**高度自适应**（按换行后行数计算，同行取最高），图片高度按绘制流程精确计算，**文字不溢出**。支持「农场商店 展开 [页码]」按等级分页查看全部可购种子；「种子商店」「肥料商店」快捷指令保留（重定向到农场商店）。

- **农场系统**：完整实现——解锁农场、开垦土地、土地升级（贫瘠→红→普通→肥沃→黑）、种子商店（含等级专属价与删除线红价）、肥料商店、种植/施肥/收割/取消种植、售卖作物与种子、土地状态与农场仓库（图片）。作物与肥料可通过 WebUI 后台页自定义。

---

## v1.4.0 及更早

### 新增

- **金币银行**：新增 `存款` / `取款` / `银行统计` 指令。存储额度 = 好感度×100 + 宠物经验；利率由好感度等级（基础）+ 宠物等级（加成）在存款时随机决定；按小时计息，下一个 4:00 解锁，利息自动入账，本金待主动取款。

- **文字转图片发送**：`商店`、`打工`、`玩耍` 三个列表回复改为渲染成图片发送，使用 `OPPOSans-M.ttf` 字体（字体放插件目录，AstrBot 环境需有 Pillow；字体或 Pillow 缺失时自动回退为文本）。`打工` / `玩耍` 图片为 **1.7.1 卡片化布局**（宠物信息卡片 + 内容卡片，详见上文「打工 / 玩耍列表图片」）。

- **数据文件迁移**：`data.json`、`后台.txt`、生成的图片等运行数据改存到 AstrBot 的 `plugin_data/astrbot_plugin_signin/` 目录（不再放 plugins 目录）。首次加载会把插件目录里旧的数据文件自动迁移过去；`OPPOSans-M.ttf` 字体作为静态资源仍留在插件目录。
