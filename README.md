# 签到娱乐系统

一个功能丰富的 AstrBot 群聊娱乐插件（原 `astrbot_plugin_signin`），包含 **签到、左轮手枪、宠物养成、金币银行、农场、金币红包、活动中心、排行榜** 等系统。

> 🤖 本插件由大模型辅助开发完成。
>
> 💡 所有指令**直接发送即可触发，无需前缀或 @ 机器人**；金币、好感度、宠物、农场等数据**跨群聊共享**（按用户维度）。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 签到 | 每日签到获得金币、好感度与随机奖励 |
| 左轮手枪 | 金币下注、轮流开枪的对局玩法 |
| 宠物系统 | 养成、打工、玩耍、商店、看家与自动化 |
| 金币银行 | 存款生息、取款、贷款与金币账单 |
| 农场 | 解锁土地、种植收割、施肥、售卖与偷菜 |
| 金币红包 | 在群内发红包、抢红包 |
| 活动中心 | 查看并参与正在进行的活动 |
| 排行榜 | 金币 / 宠物 / 农场排行榜 |
| 后台管理 | WebUI 可视化配置与运行记录 |

---

## 一、签到

| 指令 | 功能 |
| --- | --- |
| `签到` / `我的签到` | 每日签到，获得金币、好感度、宠物经验与随机额外奖励；回复为个人数据概览图片 |
| `修改昵称 <昵称>` | 设置自定义昵称，用于各项响应与排行榜 |
| `签到帮助` | 查看签到模块指令 |
| `游戏帮助` | 查看全部模块指令 |

- 随机额外奖励可能是「属性丸」或「农场经验球」
- 未开通宠物 / 农场时，对应道具会自动折算为金币

## 二、左轮手枪

| 指令 | 功能 |
| --- | --- |
| `装弹 <子弹数> <金币>` | 发起一局 |
| `加入` | 加入本局 |
| `开始` | 发起人提前开始 |
| `开枪` | 轮到自己回合时开枪 |
| `我的战绩` | 查看胜率、净收益与金币往来 |
| `左轮手枪帮助` | 查看本模块指令 |

- 轮流开枪，中弹者判负；失败者赌注扣除手续费后由赢家分配

## 三、宠物系统

| 指令 | 功能 |
| --- | --- |
| `解锁宠物` | 领养宠物 |
| `宠物` | 查看宠物总览（等级、经验、五属性、状态与自动化信息） |
| `更改宠物名字 <名字>` | 给宠物改名 |
| `打工` / `打工 <名称>` / `打工 全部` | 查看打工列表 / 进行打工 |
| `玩耍` / `玩耍 <名称>` / `玩耍 全部` | 查看玩耍列表 / 进行玩耍 |
| `商店` | 查看宠物商店 |
| `购买 <道具名> [数量]` | 购买道具 |
| `使用 <道具名> [数量]` | 使用道具 |
| `背包` | 查看持有的道具 |
| `看家 开` / `看家 关` | 设置宠物看家 |
| `治疗宠物` | 治疗虚弱状态的宠物 |
| `自动照顾 开` / `自动照顾 关` | 开启 / 关闭自动照顾（旧指令「自动购买 开/关」仍可用；五属性变化后与定时巡检自动检查，任一属性进入第 3/4 档或体力不足时按 健康>饱食>口渴>心情>体力 补到目标） |
| `自动打工 开` / `自动打工 关` | 开启 / 关闭自动打工 |
| `自动化` | 查看自动化状态与相关指令 |
| `结算日志` | 查看自动照顾 / 自动打工记录 |
| `自动化帮助` | 查看自动化玩法说明 |
| `宠物帮助` | 查看宠物模块指令 |

- 宠物属性：饱食度、口渴值、体力、心情值、健康度、经验
- 宠物每天会自动结算属性变化；健康归零会进入虚弱状态并锁定宠物功能，治疗后可恢复
- 打工 / 玩耍按项目消耗属性并给予报酬，项目内容可在 WebUI「打工玩耍」中自定义
- 商店道具分为食品 / 饮料 / 药物 / 玩具四类，使用道具时按好感等级加成
- 自动化：五属性变化后与定时巡检自动照顾宠物（按 健康>饱食>口渴>心情>体力 补到目标，体力不足自动使用体力丸），自动打工赚取金币填补照顾花费

## 四、金币银行

| 指令 | 功能 |
| --- | --- |
| `存款 <金额>` | 存入金币，到期后自动解锁并发放利息 |
| `取款 <金额>` | 取出已解锁的本金 |
| `银行统计` | 查看存款次数、生效存单、利息总额与存储额度 |
| `查询流水` / `流水查询` / `消费记录` | 查看金币变动流水（金币账单） |

- 存款额度与利率随好感度、宠物等级变化

### 银行贷款

| 指令 | 功能 |
| --- | --- |
| `借款 <套餐代码> <金额>` | 申请贷款；不带参数查看全部套餐一览 |
| `还款 <套餐代码> [金额]` | 偿还贷款 |
| `我的贷款` | 查看生效中的贷款账单 |
| `我的征信` | 查看逾期记录与生效账单 |

- 套餐类型：特别 / 一般 / 短期 / 自定义（自定义套餐在 WebUI 配置）
- 贷款额度随农场等级、好感度等级变化，宠物等级可减免利息
- 逾期会降低好感度、自动划扣金币抵债，并影响后续借款

- 宠物的看家与加护会影响偷菜结果

## 安装

1. 把整个 `astrbot_plugin_signin` 文件夹复制到 AstrBot 插件目录（通常为 `data/plugins/`）
2. 在 AstrBot WebUI「插件」页重新加载并启用
3. 群里发 `签到` 攒金币 → `解锁宠物` → 开始养成

## 后台管理（WebUI）

在 AstrBot「插件」页打开插件卡片即可进入后台管理页：

- **商店编辑**：宠物商店（食物 / 饮料 / 药物 / 玩具）与农场商店（种子 / 化肥）
- **打工玩耍**：打工 / 玩耍的项目配置
- **贷款套餐**：自定义贷款套餐
- **功能开关**：逐系统开启 / 关闭农场、签到、活动、宠物、金币红包、银行贷款、银行储蓄、偷菜等
- **设置**：按子系统分组调整全部运行参数（签到 / 宠物 / 农场 / 偷菜 / 贷款 / 红包 / 左轮手枪 / 排行榜 / 商店 / 金币账单 / 撤回 / 调试等），保存后立即生效
- **活动中心**：启用 / 停用活动并编辑活动参数
- **同义口令**：配置指令别名，发送别名等同于发送对应指令
- **数据导入导出**：一键导出 / 导入全部数据与配置，支持历史数据保留与回溯
- **运行记录**：用户信息、宠物记录、商店价格等运行数据
- **系统设置**：群昵称同步、局域网开放

## 说明

- 金币、好感度、宠物、农场数据均**跨群聊共享**（按用户维度）
- 插件回复的消息会在一段时间后自动撤回，可在 WebUI 调整
- 涉及金币变动的回复会显示当前金币余额；打工 / 玩耍的回复会显示宠物当前状态

**重做**（自动照顾 + 自动打工 + 自动化贷款 全部重写，旧自动化代码删除）

- `自动照顾 开`：开启自动照顾并同步开启自动打工，初始照顾把宠物所有属性提升到第 1 档（健康补到目标值）并记录花费；`自动照顾 关`：同步关闭自动打工
- 触发：宠物活动 / 使用道具（自动照顾自身除外）/ 每日结算导致属性变化时检查；任一属性第 3/4 档即照顾——健康补到最大值 80%（WebUI 可调），饱食/口渴/心情/体力 第 1/2 档忽略、第 3/4 档补满（体力丸 50 金币仅自动化可购）
- 道具来源：优先持有道具，没有再按手动价 × 1.1 倍（WebUI 可调）购买并立即使用
- 自动化贷款：无上限、无逾期，仅自动照顾可贷；「还款」指令或自动打工报酬偿还
- 基准金币：照顾金币消耗为加、自动打工报酬为减；基准 > 0 且自动打工开启时，选报酬最接近基准的项目打工，完成后进入下一轮
- 统一数值管理：档位由属性最大值数据推导（60%/35%/15%），不再单独配置档位阈值
- 兼容：旧开关状态与基准金币直接继承，旧自动化贷款账单自动迁移为贷款余额
